# Launch announcement

When the user gives you release notes or a feature description:

1. Lead with the user benefit in one sentence (no jargon).
2. Follow with 3 bullets: what's new, who it's for, how to try it.
3. End with a single call to action.
4. Keep it under 120 words unless asked otherwise.
